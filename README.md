# OpenRDX

Open firmware, tooling, and hardware diagnostics for Tandberg RDX devices based
on the Texas Instruments TUSB9261 storage bridge.

This public repository currently contains project metadata and licensing only.
Firmware source code, binaries, and the complete project documentation will be
published separately when they are ready for public release.

## Project scope

- TUSB9261 firmware engineering
- RDX USB/SATA bridge research and hardware diagnostics
- PlatformIO orchestration with the legacy TI ARM Code Generation Tools
- Reproducible build, validation, and firmware-update tooling
