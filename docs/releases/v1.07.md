# OpenRDX v1.07

OpenRDX 1.07 makes the installed firmware version visible to host tools and
updates receiver discovery to support both versioned and legacy OpenRDX builds.
It retains support for RDX cartridges and qualifying, unlocked standard SATA
drives in the supported Tandberg Data RDX QuikStor external USB 3.0 dock.

**This release is experimental.** Hardware validation and drive compatibility
remain limited.

## Changes

- **Accurate firmware identification:** SCSI INQUIRY reports `0107` and the USB
  device revision reports `0107h`, corresponding to OpenRDX `1.07`. Earlier
  builds used the fixed SCSI marker `0001` and USB revision `0283h`.
- **Updater compatibility:** the guarded Windows updater recognizes OpenRDX
  revisions `0107`, `0106`, and legacy `0001`. It checks that the reported disk
  revision and Windows PnP identity agree before selecting a receiver.
- **Updated installation instructions:** the matching guide covers first
  installation on compatible receivers and updates of existing OpenRDX receivers.

## Download and install

Download [OpenRDX-v1-07.zip](https://github.com/SunboX/OpenRDX/releases/download/v1.07/OpenRDX-v1-07.zip)
and extract it into its own directory. Keep the six installation files together:
the `.bin` container, FlashBurner `.hex` image, `.json` manifest, `.sha256`
checksum list, Windows updater, and `OPENRDX_USB_UPDATE.md`.

Verify every file listed in `OpenRDX-v1-07.sha256`, then follow the included
installation guide. [SHA256SUMS](https://github.com/SunboX/OpenRDX/releases/download/v1.07/SHA256SUMS)
also covers the downloadable assets, including the archives.

Installation requires Windows, elevated PowerShell, stable USB power, an empty
bay, and careful receiver selection.

| Installed receiver firmware | Procedure |
| --- | --- |
| Receiver `0283` | [First installation](https://github.com/SunboX/OpenRDX/blob/v1.07/docs/getting-started/installation.md#inspect-then-install), using `-InstallOpenRDXOnCompatibilityReceiver` and TI Command Line FlashBurner |
| OpenRDX `0107`, `0106`, or legacy `0001` with the required `OPENRDX1` update protocol | [Update existing OpenRDX](https://github.com/SunboX/OpenRDX/blob/v1.07/docs/getting-started/installation.md#update-existing-openrdx), using `-InstallOpenRDX` with the matching `.bin` and `.json` files |

Use the [complete installation guide](https://github.com/SunboX/OpenRDX/blob/v1.07/docs/getting-started/installation.md)
for commands and completion checks, and keep the
[ROM-loader recovery guide](https://github.com/SunboX/OpenRDX/blob/v1.07/docs/development/rom-loader-recovery.md)
available. Do not substitute `-Update` for `-InstallOpenRDX`; `-Update` selects
restoration of the pinned compatibility image.

## Supported hardware and limitations

This release targets the Tandberg Data RDX QuikStor external USB 3.0
compatibility receiver built around TI TUSB9261, identified before first
installation by receiver identifier `0283`. Support for other docks, bridge chips,
or receiver revisions is not established.

The version-reporting and updater changes have not been qualified on physical
hardware for this release. A reported revision does not verify the installed
image hash, and discovery alone cannot establish that a legacy build supports
the required update protocol.

Standard SATA compatibility, full RDX Manager functionality, cold starts,
large-capacity I/O, and repeated eject/reinsert operation still need broader
hardware testing. See the [firmware behavior and validation limits](https://github.com/SunboX/OpenRDX/blob/v1.07/docs/reference/firmware-behavior.md#validation-boundary).
