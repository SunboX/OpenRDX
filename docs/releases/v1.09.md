# OpenRDX v1.09

OpenRDX 1.09 adds guarded serial-number repair and stronger manufacturing-data
protection.

- Allows a management utility to set a ten-digit unit serial while preserving
  other valid manufacturing fields and neighboring flash data.
- Requires an explicit fallback initialization when manufacturing data is
  completely erased. Partially damaged records are rejected.
- Checks the device's expected data before writing and verifies the complete
  manufacturing sector afterwards.
- Rejects legacy full-chip erase commands. The unprotected compatibility
  installer is disabled before it can change the receiver.

The USB serial keeps its existing format: `00` followed by the ten unit digits.
Changing the serial takes effect after a reset. Firmware does not automatically
replace missing manufacturing data with a newly chosen identity.

Use the [installation guide](../getting-started/installation.md) for supported
update routes. The [serial repair guide](../development/serial-number-repair.md)
describes required backups, the utility command, and verification limits.
This build remains experimental; the new serial-write flow still requires
physical-device validation.
