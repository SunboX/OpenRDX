# OpenRDX v1.10

OpenRDX 1.10 adds full manufacturing-data restore from a saved backup using
OpenRDXManager.

- Restores the complete manufacturing record, including the saved serial number
  and other saved manufacturing fields. No manufacturing values are invented.
- Preserves neighboring flash data and verifies the entire affected sector
  before reporting success.
- Requires an empty, idle dock and rejects malformed requests, invalid backups,
  changed device data, and overlapping firmware-update activity.
- Keeps the current USB identity until a manual power cycle. After a restore
  starts, another restore, serial edit, or firmware update requires a restart.
- Reports flash-read failures instead of returning stale data during backup or
  verification. Existing serial-repair and firmware-update preservation remain
  available.

Use a version of OpenRDXManager with manufacturing backup and restore support.
Back up manufacturing data before updating and keep the file outside the dock.
The Manager's automatic backup before an update is a Manager feature; firmware
cannot ensure that a different update tool saves a backup. Installing this
release adds the restore command; it does not automatically restore a record
or remove the Manager's device and serial matching checks.

Supported hardware remains the Tandberg Data RDX QuikStor external USB 3.0
TUSB9261 compatibility receiver identified by receiver identifier `0283`.
Support for other receiver families is not implied.

This release remains experimental. Automated tests exercise the receiver and
flash handling with simulated hardware; a physical manufacturing restore and
power-loss recovery have not yet been validated. Interrupted sector programming
can damage the record and neighboring data. Keep power stable throughout a
restore, and manually power-cycle the dock only after verified success.
