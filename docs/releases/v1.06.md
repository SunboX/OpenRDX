# OpenRDX v1.06

OpenRDX 1.06 is the first public release of firmware that brings compatible,
unlocked **standard SATA drives** to the supported Tandberg Data RDX QuikStor
external USB 3.0 dock while retaining RDX cartridge support.

**This release is experimental.** Compatibility and hardware validation remain
limited. Read the supported-hardware requirements and installation procedure
before programming a receiver.

## What this release provides

- **RDX cartridges and standard SATA media:** RDX cartridges retain their
  validated user-data area and cartridge access checks. Qualifying standard SATA
  drives expose their native capacity after guarded admission.
- **One stable removable USB drive:** the receiver remains discoverable with an
  empty bay or rejected medium. Media becomes ready only after its checks pass.
- **Write protection and controlled ejection:** cached cartridge write-protection
  state gates writes and UNMAP; supported host and button eject requests
  coordinate with storage activity and removal locks.
- **Receiver operation:** front-panel indication, mechanism control, insertion
  handling, and temperature-dependent fan service are integrated.
- **Selected RDX Manager functionality:** receiver discovery, identity and
  status, selected controls, diagnostics, eject policy, and integrity-checked
  firmware updates.
- **Receiver identity preservation:** USB serial identity derives from the
  receiver's validated manufacturing record, with a fallback for an invalid or
  unreadable record.
- **Complete release files:** firmware images, portable manifest, SHA-256
  checksums, guarded Windows updater, matching documentation, and build records.

See [Using OpenRDX](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/getting-started/using-openrdx.md)
and the [firmware behavior reference](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/reference/firmware-behavior.md)
for detailed behavior and remaining validation work.

## Supported hardware

This release targets the **Tandberg Data RDX QuikStor external USB 3.0
compatibility receiver built around TI TUSB9261**, identified before first
installation by vendor firmware revision **`0283`**.

OpenRDX reports receiver revision **`0001`** after installation. That field
identifies the firmware family; it does not independently identify the installed
OpenRDX release. Support for other docks, bridge chips, or receiver revisions is
not established. Standard SATA support requires a compatible, unlocked drive;
compatibility with every HDD or SSD is not promised.

## How to install

Extract the complete installation ZIP into its own directory. Keep the six
installation files together and follow its **`OPENRDX_USB_UPDATE.md`**. Verify
every file listed in the matching `.sha256` file before running the updater.
The [full installation guide at v1.06](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/getting-started/installation.md)
contains the checksum commands, target-selection checks, and complete procedure.

Installation requires **Windows, elevated PowerShell, stable USB power, an empty
bay, and careful receiver selection**. Physically remove the cartridge and close
RDX Manager and other applications accessing the receiver.

| Installed receiver firmware | Installation route |
| --- | --- |
| Vendor `0283` | [First installation](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/getting-started/installation.md#inspect-then-install), using `-InstallOpenRDXOnCompatibilityReceiver` and TI Command Line FlashBurner |
| OpenRDX `0001` with the required `OPENRDX1` update protocol | [Update existing OpenRDX](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/getting-started/installation.md#update-existing-openrdx), using `-InstallOpenRDX` with the matching `.bin` and `.json` files |

For first installation, install TI Command Line FlashBurner before starting and
follow the updater's two power-cycle prompts with J7 open. For a supported
existing OpenRDX build, the normal update activates through an automatic reset.
Do not interrupt power during transfer or programming. Follow the complete guide
for inspection, commands, and completion checks.

**Do not substitute `-Update` for `-InstallOpenRDX`: `-Update` selects restoration
of the pinned vendor firmware.** Revision `0001` and successful discovery alone
do not establish that an earlier build supports the required update protocol.

Keep the matching HEX image and
[ROM-loader recovery guide](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/development/rom-loader-recovery.md)
available before starting. SHA-256 checks validate file integrity against the
published values; the firmware is not advertised as signed.

## Known limitations

Hardware coverage is limited. Standard SATA testing currently covers one 3 TB
Seagate ST3000LM024; compatibility with other drives and full RDX Manager
functionality are not established. Cold starts, large-capacity I/O, and repeated
eject/reinsert operation still need broader testing. See the
[compatibility and validation details](https://github.com/SunboX/OpenRDX/blob/v1.06/docs/reference/firmware-behavior.md#validation-boundary).
